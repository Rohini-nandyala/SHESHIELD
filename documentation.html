1. Project Overview

Website Category

Women's Safety / Social Awareness Website

Team Name

2. Why We Chose This Project

Women's safety is a significant concern in society. We chose this project to create a platform that spreads awareness, provides emergency support information, and educates users about personal safety. Through this project, we also applied our frontend development skills to build a responsive and user-friendly website that can make safety information easily accessible.

3. Project Description

SheShield is a fully responsive Women's Safety website developed using HTML, CSS, and JavaScript. The website provides safety tips, emergency helpline numbers, an SOS emergency popup, awareness statistics, and a contact page. The goal of the project is to create an informative and interactive platform that empowers women and promotes personal safety.

4. Objectives

  • Build a responsive website
  • Promote women's safety awareness
  • Provide emergency helpline information
  • Improve UI/UX design skills
  • Practice JavaScript concepts
  • Learn responsive web development
  • Deploy the project using GitHub and Vercel
