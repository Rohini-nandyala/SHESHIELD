# 🛡 SheShield – Women's Safety & Emergency Support System

## 📖 Project Overview

SheShield is a responsive Women's Safety website developed using HTML, CSS, and JavaScript. It provides emergency support information, safety awareness, useful safety tips, and an SOS feature to promote women's safety and confidence.

---

## ✨ Features

- Responsive Home Page
- About Section
- Mission Section
- Women's Safety Statistics
- Emergency SOS Popup
- Safety Tips
- Contact Form
- Project Documentation Page
- Smooth Navigation
- Interactive Popups

---

## 💻 Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts (Poppins)

## 🚀 How to Run the Project

1. Download or clone the repository.

2. Open the project folder.

3. Open `index.html` in any modern web browser.

No installation is required.
